# Chamber seals — where each file came from

Rendered to 288 px wide from the Wikimedia Commons file named; nothing cropped,
recoloured or redrawn. Commons stopped serving arbitrary thumbnail widths in
2025 — only 120, 250, 330, 500, 960, 1280, 1920 and 3840 are accepted — so each
file was fetched at 960 px and resampled down to 288. Files whose Commons
original is a raster smaller than 288 px are marked in the Rendered column.

A row keyed `XX:` is the jurisdiction's own Great Seal and stands in wherever a
row carries no chamber. A row keyed `XX:House`, `XX:Senate` or `XX:Assembly`
exists only where that chamber has a seal of its own on Commons; the rest fall
through to the jurisdiction.

## Sourced from the chambers themselves

chambers publish on their own sites. These came from the primary source. They
are official state emblems rather than freely-licensed media: they are used
here to identify the body each row belongs to, which is nominative use, but
they are not public domain and are not interchangeable with the Commons files
above.

## Not harvested

No chamber seal was skipped for licensing. What is missing is missing because
the chamber has no seal of its own — checked against Commons, against the
English Wikipedia, and against the chamber's own website.

| Chamber | Reason |
|---|---|
| Alabama House and Senate | Only the Speaker's seal exists on Commons; alison.legislature.state.al.us brands both chambers with one Alabama Legislature logo. |
| Arkansas Senate | senate.arkansas.gov carries a horizontal wordmark, not a seal. |
| Arizona House and Senate | azhouse.gov and azsenate.gov carry wordmark lockups, not seals. |
| Connecticut House | Only the General Assembly's seal exists — the whole legislature's, not the House's. |
| Michigan House and Senate | Both use modern brand lockups (`HouseLogo.png`, `Brandmark - Red.png`), not seals. |
| Maine House | legislature.maine.gov/house carries a horizontal wordmark. |
| Nevada Assembly and Senate | The Legislature's 1967 emblem covers both chambers. |
| North Carolina House | Only the Speaker's seal exists. |
| Utah Senate | senate.utah.gov's header image is `state_seal_small.png` — the Utah state seal. |
| Wyoming House and Senate | Only `Seal of the Wyoming State Legislature` exists, covering both chambers, and it is trademarked. |
| Alaska, Colorado, Delaware, DC, Hawaii, Illinois, Indiana, Iowa, Kentucky, Maryland, Minnesota, Mississippi, Montana, New Hampshire, New Jersey, North Dakota, South Dakota, Tennessee, Vermont, Virginia House, West Virginia, Wisconsin | The legislature brands itself as one body (a single legislature-wide logo or the state seal). These chambers fall through to the state seal. |
